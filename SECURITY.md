# Security Policy

## Defensive Use Purpose
AutoSOC is an academic project designed for defensive cybersecurity. The tools and techniques developed here must not be weaponized or used against unauthorized targets.

## Vulnerability Reporting
*Note: This is an academic project without a dedicated security email alias yet.*
If you discover a vulnerability, please open a GitHub Issue titled **[SECURITY]** and do NOT include active exploits or live credentials in the issue body. 
In a production deployment, this would be reported via a private channel.

## Malicious Test Data
Do not commit live malware or real exfiltrated data to this repository for testing. Use synthetic or sanitized datasets (e.g., standard PCAPs or synthetic logs) exclusively.
