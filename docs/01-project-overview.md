# Project Overview

## 1. Project Background
Modern Security Operations Centers (SOCs) are inundated with security alerts, leading to alert fatigue, missed true-positives, and increased time to resolution. Existing rule-based SIEMs struggle to identify novel attacks (zero-days) effectively, while purely automated response systems carry high operational risks if they act autonomously on false positives. There is an industry need for a system that bridges the gap between AI-driven rapid analysis and human-approved safe containment.

## 2. Problem Statement
Security teams cannot keep pace with the volume of alerts and the sophistication of modern threats. Zero-day attacks and stealthy lateral movements often go undetected by deterministic rules. Furthermore, manual investigation of every suspicious anomaly is too slow. The core problem is the lack of a unified, AI-assisted platform that can confidently identify potential zero-day behaviors, predict attacker progression, and prepare fully contextualized, human-approvable response actions.

## 3. Proposed Solution
AutoSOC is an Agentic AI-Driven Autonomous Security Operations Center. It addresses the problem by combining robust event ingestion with a hybrid detection engine (deterministic rules + machine learning). When an anomaly is detected, AutoSOC correlates events into an incident, maps the behavior to the MITRE ATT&CK framework, and employs Agentic AI to investigate the incident. The AI formulates an attack-progression prediction and recommends a set of allowlisted response actions, which are executed only upon approval by a human SOC Analyst.

## 4. Primary Objective
Design and develop an industry-style autonomous Security Operations Center platform that collects, normalizes, and analyzes security events to detect known attacks and suspicious unknown behaviors, correlates these into incidents, predicts attacker progression, and supports controlled AI investigation with human-approved response actions.

## 5. System Users and Roles
- **Administrator**: Manages users, roles, data sources, detection rules, and thresholds. Views system health and manages approved response playbooks.
- **SOC Analyst**: Monitors alerts, investigates incidents, reviews evidence, adds notes, approves/rejects response actions, and closes/escalates incidents.
- **Security Manager**: Views incident trends, organizational risk metrics, SOC performance, and management reports.
- **Auditor**: Has read-only access to review incidents, audit logs, and response-action history, and can export reports.

## 6. Major Components
1. **Event Ingestion & Processing**: Redpanda for streaming, FastAPI workers for validation, OCSF-inspired normalization, and enrichment.
2. **Detection Engine**: Rule-based (Sigma-style) matching and ML-based anomaly detection (PyTorch/scikit-learn).
3. **Storage**: PostgreSQL for relational data, OpenSearch for log search and analytics, MinIO for object storage, Redis for caching.
4. **Agentic AI & Orchestration**: LangGraph and local Ollama LLMs for investigation, RAG, and response recommendation.
5. **Frontend UI**: Next.js dashboard with interactive visualizations (Apache ECharts, Cytoscape.js).

## 7. Academic Contribution
As a final-year academic project, AutoSOC demonstrates the integration of production-oriented software engineering, artificial intelligence (specifically Agentic workflows and ML anomaly detection), observability, and secure deployment practices within a single, cohesive cybersecurity platform. It contributes a reference implementation of a safe, human-in-the-loop autonomous security investigation system.

## 8. Expected Outcomes
- A functional MVP deployed via Docker Compose.
- A fully documented, production-style Kubernetes deployment configuration.
- Comprehensive technical and management reports generated by LLMs based on real or synthetic incident data.
- Demonstrable ability to detect known attacks and flag suspicious, previously unseen behaviors.
- An interactive attack-graph showing predicted lateral movement.
