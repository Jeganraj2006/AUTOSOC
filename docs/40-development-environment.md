# Development Environment

## Supported OS
- Linux (Ubuntu)
- macOS
- Windows (via WSL2 recommended, or PowerShell for core Python/Node tasks)

## Required Tools
- **Node.js**: v20.x
- **Package Manager**: pnpm v9.6.x (use via `npx pnpm@9.6.0` if not globally installed)
- **Python**: v3.12.x
- **Python Manager**: uv v0.4.x
- **Git**: v2.30+

## IDE Recommendations
- **VS Code**:
  - Extensions: Ruff, ESLint, Prettier, Tailwind CSS, Python (Microsoft)
- **PyCharm / WebStorm**:
  - Ensure the Ruff plugin is enabled instead of standard Black/Flake8.
